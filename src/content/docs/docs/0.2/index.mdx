## What ParqDB supports today

| Runtime | Storage | Capability | Status |
| --- | --- | --- | --- |
| Embedded DataFusion | Parquet | Build and query IVF, IVF-LVQ4, and IVF-LVQ8 | Supported |
| Browser/WASM | Public HTTPS object storage | Query immutable IVF-LVQ indexes over HTTP Range | Experimental |
| Embedded DataFusion | Iceberg | Query exact snapshots through the native provider | Experimental |
| Client/server | Authorized Parquet sources | Build and query through the HTTP API | Experimental |

The embedded DataFusion runtime is the first supported product surface. Review [current limitations](/docs/0.2/reference/limitations) before planning a production deployment.

## Choose a deployment shape

| If you need | Start here | What runs the query |
| --- | --- | --- |
| A local Python application or notebook | [Embedded ParqDB](/docs/0.2/guides/embedded) | DataFusion in your Python process |
| A public, serverless search experience | [Publish for the browser](/docs/0.2/guides/browser) | WebAssembly in each visitor's browser |
| A shared API for trusted clients | [Run a server](/docs/0.2/guides/server) | The ParqDB process behind HTTP |

All three paths use the same immutable Parquet index format. The browser path
has a deliberately smaller feature surface; the [limitations page](/docs/0.2/reference/limitations)
defines the current boundary.

## Install

```bash
python -m pip install parqdb
```

```python
import parqdb

session = parqdb.connect("./parqdb-data")
session.register_parquet("documents", parqdb.datasets.uri("documents"))
documents = session.table("documents")
```

Continue with [Getting started](/docs/0.2/getting-started) to build and query your first index.

## Before production

1. Confirm the source schema and stable key fields in [Getting started](/docs/0.2/getting-started#use-your-own-parquet-table).
2. [Tune the IVF index](/docs/0.2/guides/index-tuning) against representative queries and measure recall, latency, and I/O together.
3. Set explicit [resource and cache limits](/docs/0.2/reference/configuration).
4. Review [current limitations](/docs/0.2/reference/limitations) and the [troubleshooting guide](/docs/0.2/reference/troubleshooting).
